## 三条采集纪律

1. **只读**：全程只做页面跳转与弹窗展开，弹窗截图后一律点「取消 / 关闭」，未触发任何保存、提交、删除、确认类写操作，平台数据零变更。
2. **可复现**：`_meta/capture.py` 一条命令重建全部截图；失败自动重试一次，仍失败则记入 `manifest.errors` 并继续，不阻塞队列。
3. **有据可查**：文档中的列名、字段、规则文案均取自真实 DOM（`dom.json` / `dialogs.json`）与前端 chunk，不靠推测。

## 复现命令

```powershell
cd "管理端\_meta"
python capture.py          # 重建截图（约 6~8 分钟）
python extract_dom.py      # 刷新 dom.json
python extract_dialogs.py  # 刷新 dialogs.json
python build_gallery.py    # 重建 index.html
```

依赖：Python 3.13 + `playwright` + 本机 Chrome（脚本用 `channel="chrome"`）。
可选环境变量：`ADMIN_BASE` / `ADMIN_USER` / `ADMIN_PASS`。

## 需要注意的 9 处差异

逐页巡检发现实现与文案不一致的地方，已在文档[附录 C](管理端功能说明.md#附录-c-实测差异与建议) 详列，摘要：

1. 菜单「统一登录配置」在菜单树中存在但前端未注册路由，点击静默回落到总览页。
2. 总览底部「本期交付范围」把已上线的能力工坊/授权台/审批中心写成"后续阶段"。
3. 权限点数量两处不一致：文案「46 个（高敏 6）」，实际 77 个（高敏 12）。
4. 「运维管理」与「模型管理」菜单排序值同为 35。
5. 知识库管理为纯占位空态，但授权台已存在 `knowledge` 类资产。
6. 审批中心角标（独立接口）与列表（另一接口）不同源，并发提交时短暂不一致。
7. 管理端密码最小长度仅 6 位且无复杂度约束。
8. 组件「已上架 5」与市场源「4 个组件 / 7 个版本」不一致——`due-suite` 无包体进不了市场。
9. 连接器/能力目录中混入多条「冒烟连接器」测试残留。
